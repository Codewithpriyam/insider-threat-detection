01 // PROJECT INTRODUCTION

SYSTEM OVERVIEW & CORE CONCEPTS

WHAT IS USER BEHAVIOR ANALYTICS (UBA)?

  • Behavioral Identity Shift: Shifts security monitoring from perimeter firewalls to internal identity and activity patterns.
  • Contextual Audit Ingestion: Ingests normalized event streams across authentication, document access, download volumes, and roles.
  • Rolling Sliding-Window Engine: Analyzes user behaviors across 10-minute intervals to catch fast-moving anomalies before data leaves.
  • Zero-Lag SOC Triage: Dispatches instant alerts to a real-time Security Operations Center feed with one-click containment.

TECHNICAL FOUNDATIONS & METHODOLOGY

  • Java Spring Boot 3 Service: Implements deterministic, sliding-window heuristics with JPA repositories and in-memory H2 / MySQL.
  • React 19 Frontend UI: Built under the VoiceBox Editorial Brutalist Design System (0px border-radius, pure monochrome + red accent).
  • In-Browser Dual-Mode Engine: Seamlessly executes identical heuristics directly in JavaScript when running standalone on GitHub Pages.
  • Spec-Driven Development: Built to rigorous SpecKit engineering standards for complete audit transparency and reproducibility.
02 // PROBLEM STATEMENT

THE INSIDER THREAT CRISIS

THE PERIMETER DEFENSE PARADOX

  • The Inside Advantage: Attackers operate with valid credentials, approved workstations, and legitimate corporate network access.
  • Perimeter Blindness: Firewalls, VPNs, and Network IDS cannot distinguish between routine business queries and mass data exfiltration.
  • Severe Containment Lag: According to Ponemon Institute, average insider incident detection and containment takes over 85 days.
  • High Financial Damage: Average annual insider breach cost exceeds $16.2M, accompanied by severe GDPR and HIPAA liabilities.

RESEARCH & ENGINEERING OBJECTIVES

  • Objective 1 (High-Speed Ingestion): Ingest large batch CSV files (up to 200MB) and streaming logs with automatic delimiter detection.
  • Objective 2 (Transparent Heuristics): Implement deterministic sliding-window rules providing clear forensic reasoning for every alert.
  • Objective 3 (Immediate Containment): Equip security operators with 1-click threat resolution linked directly to raw evidence logs.
  • Objective 4 (Zero False Positives): Maintain 0% false positive rates on routine daytime activity while ensuring 100% threat detection.
03 // THREAT VECTOR SCOPE

THREE CORE ATTACK VECTORS DETECTED

VECTOR 01

UNUSUAL ACCESS PATTERNS

Brute Force & Off-Hours Logins

  • Off-Hours Access: Logins between 11:00 PM and 5:00 AM outside routine operating hours.
  • Brute-Force / Stuffing: >3 consecutive failed login attempts within 10-minute sliding window.
  • Severity: HIGH / MEDIUM
  • Impact: Detects credential stuffing, compromised VPNs, and unauthorized midnight browsing.
VECTOR 02

MASS DATA EXFILTRATION

Spike Downloads & Large Transfers

  • Download Spikes: >10 file downloads within a 10-minute sliding window.
  • Volume Exfiltration: Total transferred bytes exceeding 150 MB within rolling period.
  • Severity: HIGH
  • Impact: Prevents theft of source code, proprietary algorithms, databases, and customer PII.
VECTOR 03

PRIVILEGE ESCALATION

Unauthorized Role Modification

  • Unauthorized Promotion: Standard user account self-assigning ROLE_ADMIN or IAM access rights.
  • Access Group Tampering: Modifying privileged roles without supervisor approval signatures.
  • Severity: CRITICAL
  • Impact: Blocks administrative takeovers and prevents audit trail tampering.
